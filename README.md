# Sesh Starter for Windows

Public beta 0.11.4. Free BPM and musical key finder for producers and artists.

Download and setup: https://seshstarter.com/windows.html

Extract the complete Windows-x64 ZIP into a writable folder and open SeshStarter.exe. Windows 10/11, 64-bit. Initial audio and YouTube setup requires internet. Keep data and tools when updating.

BPM and key are estimates. The executable is not Authenticode-signed; updates use a separate RSA signature and SHA-256 verification.

Feedback: contact@seshstarter.com

macOS remains in separate beta testing.

0.11.4: baseline-aligned BPM and major/minor result labels with responsive sizing; helpful unavailable-video errors.
